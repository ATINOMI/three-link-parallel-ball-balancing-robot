# 20Hz二阶巴特沃斯：速度反馈滤波与相位估算

滤波前Git留档：`940b6b4`，标签`before-butterworth-20261028`。该基线采用5ms角度窗口测速、时间常数20ms的一阶低通。

本次用一个二阶Butterworth biquad替换原一阶低通，不串联两级滤波。默认滤波更新200Hz（5ms）、截止20Hz；速度环默认也为200Hz，但两者可独立调节。原始角度窗口测速仍约200Hz；重力运动方向判断继续使用未滤波角度窗口速度，静摩擦撤销继续使用原始累计位置。

## 默认200Hz时的数字滤波器

采用双线性变换并对截止频率预畸变。令`K=tan(pi*fc/fs)`，`N=1/(1+sqrt(2)*K+K²)`，则：

```
b0=K²*N, b1=2*b0, b2=b0
a1=2*(K²-1)*N, a2=(1-sqrt(2)*K+K²)*N
H(z)=(b0+b1*z^-1+b2*z^-2)/(1+a1*z^-1+a2*z^-2)
```

默认系数：

`b=[0.067455273889, 0.134910547778, 0.067455273889]`

`a=[1, -1.142980502540, 0.412801598096]`

因此，在5Hz、10Hz附近，新滤波比旧一阶分别减少约10.81°、3.83°的相位滞后；在20Hz处则增加约36.88°。是否改善稳定裕度取决于实际开环交越频率，不能将20Hz截止、200Hz更新频率或表中滞后直接当作速度环带宽/相位裕度。

旧一阶在200Hz更新时的实际数字−3dB截止约7.13Hz；新20Hz滤波通带更宽，因此低到中频的噪声可能更大，并非所有频段都更平滑。约50Hz及以上的新滤波抑制更强。应结合实测噪声频段和速度环交越频率选择截止，而不是只看滤波阶数。

这些数字只涵盖数字低通本身，不含5ms测速平均窗（理想情况下约2.5ms平均延迟）、CAN数据龄期、速度环采样保持与执行延迟或机构动力学。完整带宽/相位裕度需结合设备当前PID和实测频响确定。

## 上位机更新频率

新增`U,<speed_period_ms>,<filter_period_ms>`。速度环周期1–50ms（20–1000Hz），滤波周期1–20ms（50–1000Hz）；1ms基础定时器使周期必须为整数。输入333Hz会采用3ms，回读333.33Hz。滤波器截止固定为20Hz（固件宏`CAN_SPEED_FILTER_CUTOFF_HZ`），调频时仅重新计算系数；原始测速窗口固定5ms。

调频会清除三路PID积分/历史并更新其dt，滤波状态按当前输出重新建立以减小切换跳变；保留目标、增益、摩擦、比例和控制模式，不会由停止状态启动电机。提高计算频率不会产生高于原始200Hz窗口测速的新测量信息。滤波运算与PID分别由1kHz中断独立分频，电流发送和静摩擦撤销仍为1ms。

V6共58字段：在V5的55字段后追加速度环周期ms、滤波周期ms、滤波截止频率×1000。旧V5可回传其他参数，但调频需要重新烧录本次V6固件。

## 调参文件

在速度环浮窗顶部选“设备已生效参数”或“当前调参表单”导出JSON。文件记录三台电机独立PID、静摩擦幅值、撤销阈值、输出比例、k_g、更新周期，表单导出表单导出另保存速度目标和测试表单。设备导出不混入尚未应用的测试表单。设备导出不混入尚未应用的测试表单。表单导出会保留尚未应用的草稿；设备导出以回读值为准。旧V5无法回读更新频率时，对应timing记录为null，不冒充实际滤波设置。

导入只载入表单，不下发控制指令。点击“应用表单中的全部参数”才发送P/R/U/K/T配置，且需先结束测试；不发送V/D/F/B/G/S，不启动速度环、不恢复摩擦，也不解除急停。速度目标和固定电流仍需另外明确启动。更改截止频率需要修改固件，文件里的cutoffHz仅是记录，应用配置以当前固件的20Hz为准。示例见`example-tuning.json`。
