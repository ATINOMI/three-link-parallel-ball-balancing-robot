## 静摩擦检测灵敏度调整（当前V5）

# 3RRS USB控制台：速度PID、重力及摩擦前馈

## 速度环使用

1. 打开“速度环调参”，选M1/M2/M3，分别设置Kp、Ki、Kd和摩擦前馈幅值（raw），点击“应用该电机参数”。以设备回读值为准；**参数默认全部为0，应用参数不会启动速度环**。运行中可调参，修改会清除该路PID历史状态。
可在速度环运行时选择电机，点击“恢复 Mx 静摩擦补偿”手动重新允许该路起动补偿。使用设备已生效的幅值和当前目标速度方向；不提交尚未应用的输入值，不改变PID、目标速度或控制模式。点击时重新记录该路编码器位置，之后首个位移仍在下一次1ms电流发送时撤掉。目标为0或摩擦幅值为0时按钮禁用。

2. 填写三台电机的目标速度（输出轴°/s，负数抬升、正数下降），点击“启动速度环”；运行中再次点击可更新目标。三路目标默认0，支持±180°/s。目标0仍由PID控制至零速，并非关闭输出。
3. “速度跟踪”显示三台电机最近20秒的目标、实测速度、误差、PID原值、摩擦原值及最终电流。它使用设备已有的**角度微分+低通滤波**速度，按减速比3591/187换算为输出轴°/s，不使用电调原始speed_rpm。关闭跟踪图只隐藏图；关闭调参浮窗会停止速度环。
4. 点击“停止速度环”或按Q：三路零电流。Esc、页面失焦/隐藏/关闭也停止速度环。恢复后需先点“启用 / 恢复重力补偿”，再启动速度环。速度目标每50ms刷新；固件超过300ms没有目标心跳、CAN反馈超过100ms或角度达到−80°，均停止三路输出；不会自动退回重力补偿输出。

## 速度环计算

普通位置式PID，计算周期5ms，三台各有上下两组参数，**按目标速度方向选择Kp/Ki/Kd，目标0沿用上一组**：

```
e = v_target - v_measured
I += Ki * e * 0.005
D = Kd * (e - e_prev) / 0.005
I_pid = Kp * e + I + D
I_friction = starting_from_rest ? sign(v_target) * friction_raw : 0
I_cmd[i] = clamp(round(output_scale[i] * (I_gravity[i] + I_pid[i] + I_friction[i])), -16384, 16384)
```

首个PID采样的D项为0，积分项及PID输出限幅±16384，并保留简单积分抗饱和。停止时清除积分和历史误差。速度模式**不使用历史的“上升开、下降关”门控**：重力前馈按姿态持续计算，k_g保留1.4；如需单独调试纯PID，可先将k_g设0。静摩擦项只在静止起动时按目标速度方向给定，直接读取累计编码器计数；收到任何方向的首个位移反馈后，在下一次1ms电流发送时清零，不等待5ms速度环、20ms低通或USB回传。清零后锁定，连续心跳和同方向目标更新不会再开启；停稳后由0目标重新起动，或停稳后给反向新目标，才重新允许补偿。运动中反向不重新加静摩擦项。`STATIC_FRICTION_REST_MS=20`仅用于判断下一次起动前是否停稳，不延迟撤销；任一编码器计数变化就清零。目标为0、退出速度模式、急停或限位时也清零。最终电流仍经过独立三路比例和总电流限幅。

默认宏在固件main.c：`SPEED_PID_UP_KP/KI/KD`、`SPEED_PID_DOWN_KP/KI/KD`、`SPEED_FRICTION_RAW`，均为0。Kp单位raw/(°/s)、Ki单位raw/°、Kd单位raw/(°/s²)，摩擦值为raw幅值。旧电流测试模式保留原行为，与速度环互斥。

## 速度环USB协议

- `K,<motor>,<kp_milli>,<ki_milli>,<kd_milli>,<friction_raw>`：分别设置某电机参数；增益×1000，motor=1–3，增益非负，摩擦幅值0–16384；不切换控制模式。
- `V,<v1_milli>,<v2_milli>,<v3_milli>`：目标速度×1000，进入mode=5，或刷新正在运行的三路目标；上位机每50ms发送。
- `B,<motor>`：手动恢复指定电机静摩擦补偿，仅当前速度模式且该路目标非0时生效；不刷新速度心跳，不解除急停或限位。
- `S`：停止并三路零电流；`G`：结束当前模式，回到历史普通模式。

V4每20ms回传一帧，共52字段。在原V3的28字段后依次追加24个整数：

```
speed_measured[3] (°/s ×1000), speed_target[3] (°/s ×1000),
M1(kp×1000,ki×1000,kd×1000,friction_raw),
M2(kp×1000,ki×1000,kd×1000,friction_raw),
M3(kp×1000,ki×1000,kd×1000,friction_raw),
pid_raw[3], friction_raw_signed[3]
```

PID及摩擦原值为三路输出比例之前的值；base是缩放并限幅的重力分量，delta是其余实际贡献，total为最终CAN指令，始终满足base+delta=total。速度窗的“实测”来自USB遥测；离线演示另用示意惯性模型，仅验证交互与跟踪流程，不代表实际装置动力学。

验证：`node tests/control.test.cjs`、`node tests/float.test.cjs`、`node tests/speed.test.cjs`。本次未烧录，也未向真实电机发送测试指令；实机验收由你进行。

三台电机首次 CAN 反馈的位置均标定为 **12.77°**，之后角度=12.77°+编码器相对变化量；上升时角度减小。CAN_ZeroMotorAngle 重新建立基准后也回到12.77°。该标定角直接参与重力计算，需在每次上电前保持相同的实际初始位形。姿态是机构模型正解得到的估计值。保持原 `k_g=1.4`；运行期间可调整系数，重启恢复固件默认值。

## 新测试逻辑

**被测电机按预定方向提前选择前馈，不等待速度反馈。** 抬升测试从第一条零增量指令开始就开启 `k_g * tau_g` 对应的电流，下降测试从第一条指令开始就关闭重力前馈；随后累加同方向的测试增量。测试中即使尚未运动或速度暂时反向，也不改变这个预先选择。

普通模式和非测试电机仍沿用第一版的 `volatile bool gravity_upward_only_mode = true;`：按实测 5 ms 角度窗口速度，上升补偿，下降/静止关闭。设为 `false` 时只改变这些非测试状态的补偿规则，不覆盖被测电机的目标方向选择。

`所选电机总指令 = 当前重力补偿指令 + 测试增量`

其余两台电机独立保留原方向补偿逻辑。重力基线随实测角度每 5 ms 更新，测试时不冻结基线。CAN 仍为 1 kHz。

1. 选择电机，设增量上限、增量速率、明显位移和最长时间。默认 0.5 A、0.1 A/s、0.5°、15 s。
2. 点击“向上测试”或“向下测试”。先记录当前起始角度，再以明确的目标方向和零增量进入测试；收到设备确认后按实际经过时间累加负/正增量。即使零增量前馈已经引起位移，也会纳入起动判断。
3. 沿测试方向超过位移阈值，连续 3 个不同遥测帧确认后自动结束。结果取首次达到阈值那一帧的**设备回传**基线、有效增量及总指令。反向位移也会结束，但标为反向响应，不算正常起动。
4. 结束后撤回增量，三台电机回到原方向补偿逻辑（默认下降和静止不补偿）。手动结束、Esc、失焦、隐藏页面、超时、正常断开同样只撤回增量。
5. “急停”是独立的三路零电流指令；急停后断开不会自动恢复补偿，只有明确点击“启用 / 恢复重力补偿”才恢复。

测试命令心跳每约 50 ms 刷新，超过 300 ms 未刷新时固件撤回增量、恢复重力补偿。因此拔掉 USB 会撤回增量，**仍按原方向逻辑决定是否补偿**，不会无条件将全部输出清零。任一电机 CAN 反馈超时 100 ms 时三路均归零，并撤销正在进行的测试；反馈恢复后回到重力补偿。固件按 C620 指令范围对总输出限幅，回传的增量为限幅后实际贡献值。

阈值结果代表“达到给定位移时的电流”，不等于精确静摩擦参数；它受到 `k_g`、机构耦合、惯性及采样周期影响。下发指令 A 按 raw×20/16384 换算；电调反馈字段单独显示 raw，避免假定未知反馈比例。

## 离线演示

可测试完整的零增量握手、自动斜坡、位移判断、结果记录和撤回流程，不会打开或写入串口。演示设置了人为起动阻力，并使用机构闭环绘制姿态；它是交互示意，不用于估计真实起动电流。

## USB V2 协议

ASCII、按换行分帧，支持 USB 分片与多行。PC→MCU：

- `P,<kg_milli>`：补偿比例乘1000，0–5000；不改变输出模式。
- `D,<motor>,<direction>,<delta_raw>`：电机1–3，direction=-1抬升（前馈开）、+1下降（前馈关）；增量 −16384…16384，符号须与方向一致。零增量也必须携带方向；每约50 ms刷新。旧三字段 D 指令不再接受。
- `G`：撤回测试增量并保持/恢复方向门控重力补偿。
- `S`：三路零输出，保持至明确的恢复操作。

MCU→PC，每约20 ms共24字段：

```
V2,ms,mode,kg_milli,testMotor,freshMask,a1_mdeg,a2_mdeg,a3_mdeg,roll_mrad,pitch_mrad,z_um,base1,base2,base3,delta1,delta2,delta3,total1,total2,total3,fb1,fb2,fb3
```

mode=0急停/1原方向补偿逻辑/2有效重力基线+增量/3固定给定前馈关/4固定给定方向前馈使能。freshMask位0–2对应电机反馈有效；角度千分之一度、姿态角千分之一弧度、Z微米，其余电流为raw。base/delta/total均取TIM6输出快照，total=base+delta；急停和反馈中断时三组均为零。回传表示提交CAN的指令，不保证电调收妥。

`node --test tests/*.test.cjs` 可运行协议、斜坡、位移判断、串口排队撤销与离线流程测试。构建与逻辑验证由本次直接实现完成，未烧录、未实机运动；界面及实际装置由你验收。

回传 base 是实际采用的前馈：抬升测试中静止时也非零，下降测试时始终为零；普通模式/非测试电机由原方向开关决定。V2 遥测仍为24字段；本版改变的是 D 指令增加显式方向参数，需要重新烧录固件并刷新上位机。参数面板的系数设置不改变方向选择。

## 固定电流指令模式（新增）

在“固定电流指令”面板使用上方选定的电机，输入 -16384 到 16384 的整数 raw 值和持续时间，点击下发。默认“启用重力前馈”关闭，该值**直接作为所选电机的总指令**。打开开关时，只有给定raw<0（抬升）才加入当前重力前馈；给定raw>=0不补偿。判断依据是给定raw的符号，不是实际速度或叠加后的总电流。两种情况下都不做斜坡，也不因达到位移阈值而结束。未选电机保留原控制逻辑。

运行中可修改 raw 和持续时间再点“更新固定指令”；更新立即替换原值并重新计时。允许正值、负值和零。点击结束或达到设定时间后，回到原补偿逻辑；失焦、隐藏页面、USB/反馈超时和急停与现有测试入口一致。默认持续10秒，可设1–60秒。

新增指令 `F,<motor>,<gravity_on>,<raw>`，gravity_on为0或1，每约50 ms刷新；mode=3表示前馈关闭，mode=4表示允许按给定方向启用前馈。仍使用24字段V2遥测：被测电机关闭前馈时base=0、total=raw；开关开启且raw<0时base为当前重力前馈、total=base+raw；raw>=0时base=0、total=raw。delta回传限幅后的有效给定分量。其余电机base与total保留原逻辑。只有顶部三项和固定模式结果使用raw显示，其他原有A显示维持不变。

此功能需要重新烧录本次新固件并刷新页面。旧固件不识别F指令，会显示“设备未确认固定指令，请更新固件”，不会用旧的增量测试代替。

固定指令面板现为同页浮窗：可拖动标题栏（键盘聚焦标题后可用方向键移动），浮窗内直接选择电机。关闭会结束固定测试并回到原控制逻辑，右下角按钮可重新打开；打开本身不会下发指令。

快捷键：控制台页面有焦点时按 **Q**（大小写均可）发送与急停按钮相同的 S 指令，立即结束测试并请求三路零电流；输入框或浮窗内也生效。浏览器地址栏或其他应用获得焦点时，页面无法接收该按键。Esc 仍只结束测试、恢复原控制逻辑。

固定给定的重力前馈开关默认关闭；未启动时切换只配置下次测试，运行中切换立即发送新指令并重新计时，保留已经生效的给定raw值，不会自动提交输入框里尚未点击更新的新raw值。

固定模式：前馈开关开启只是允许补偿；仅给定raw为负时实际补偿，给定为正或零时不补偿。默认开关关闭。

角度保护：固件每1 ms直接读取编码器角度，任一电机角度≤−80°，或该路曾进入负角度后返回到/跨过0°（角度≥0°），三路总电流指令（含重力、PID、静摩擦和测试电流）归零并锁定，退出测试。上电默认+12.77°不会触发0°保护，从正角度首次进入负角度也不会触发；三路分别记录是否进入过负角度。持续测试指令不能解除锁定。恢复时，先将所有电机移回大于−80°，且已进入过负角度的电机必须小于0°，再点击“启用 / 恢复重力补偿”。此功能需要重新烧录固件。

## 三路独立输出比例

固件 `Core/Src/main.c` 顶部宏 `MOTOR_1_OUTPUT_SCALE`、`MOTOR_2_OUTPUT_SCALE`、`MOTOR_3_OUTPUT_SCALE` 定义各路上电默认比例，默认均为1.0f。运行值为 `motor_output_scale[3]`。

各路最终输出=限幅(round(该路缩放前总电流 × 对应比例))，范围仍为±16384。重力补偿、增量测试及固定给定都经过比例；比例为0时该路输出为0。k_g仍只调整重力补偿。负指令是否开启前馈仍按缩放前给定指令方向判断。−80°限位及急停始终将三路清零。

上位机“重力补偿基线”面板可分别输入三路比例（0–5，步长0.001），在测试结束后点击“应用三路输出比例”。收到设备回传后显示实际值；修改只保存在RAM，重启恢复宏默认值，不写Flash。

新增命令 `R,<scale1_milli>,<scale2_milli>,<scale3_milli>` 一次设置三路比例，整数0–5000；修改比例不启动输出或解除急停。固件遥测升级为V3，在原V2的24字段后追加三路比例×1000和实际采用的缩放前测试给定raw，共28字段。base为缩放并限幅后的重力分量，delta=最终限幅总指令−base；两者使用32位回传以容纳分量之差，仍满足total=base+delta，只有total作为CAN电流指令。界面可以读取旧V2，但修改比例需要重新烧录新固件并刷新页面。
