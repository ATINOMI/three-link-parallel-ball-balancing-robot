## 角度环最小角速度（V11）

每个电机新增一个上下方向共用的minSpeed（输出轴°/s），默认0，范围0～该电机maxSpeed。仅在误差超出到位范围时，将非零角度PID速度输出的绝对值抬至此下限，保留PID符号；PID本身输出0仍保持0。进入到位范围的稳定确认期间不抬高，稳定到位后仍输出0；速度内环、急停和超时逻辑不变。

J扩展为 `J,motor,direction,kp_milli,ki_milli,kd_milli,max_speed_milli,min_speed_milli`，一次原子配置。旧6参数J继续兼容，下限恢复0。V11保留V10的105字段，再追加三路minSpeed×1000，共108字段，文本上限1280不变。JSON仍version3，可选position.pid[i].minSpeed；旧文件/旧帧不伪造新字段，旧固件保持原角度功能，但不能下发带minSpeed的新配置。设备回读确认包含下限，不得用发送值冒充已生效。

固件提供ANGLE_MIN_SPEED_DPS默认宏。界面入口在角度环调参，按M1/M2/M3选择，切换方向仍共享该电机下限；导入、导出、批量配置与离线演示同步支持。手柄上位机仅补V11解析与运行兼容，不更改用户保存在浏览器的轴向/灵敏度设置。新功能需重新烧录，未执行自动烧录或实机运动。

## 连续稳定到位与暂停纠偏（当前V9）

默认允许误差为目标角度±0.5°，连续处于范围内20ms才视为该电机成功到位。固件每1ms使用原始编码器角度独立检查三路；确认期内仍继续角度PID调整。短暂经过目标、从范围外重新进入，都必须重新计满稳定时间。

成功后清除该路角度PID历史并将其目标速度设为0，暂停角度外环调整；速度内环继续以0°/s控制，并非断电或急停。其他电机的角度控制不受影响。误差再次严格超过允许范围（默认>0.5°）时立即撤销到位标记，在下次角度/速度PID周期恢复纠偏；重新到位仍须连续稳定确认。范围边界包含在内。

“角度环调参”浮窗新增“三路共用”的允许误差和连续稳定时间，分别支持0.001～10°、1～5000整数ms；每路计时和到位状态独立。下方及角度跟踪读数显示“纠偏中 / 范围内·稳定确认中 / 成功到位·暂停角度纠偏”。三路全部到位时显示三路成功，控制模式和目标心跳继续运行，以便检测扰动后自动恢复。关闭调参、Q、失联和限位仍按原逻辑停止。

相同目标的A心跳不会重置计时；更改某一路目标会只对该路重新判定。修改到位设置、PID周期或该路正在使用的角度PID/速度上限，会重新开始相应稳定判定。到位不限制上位机继续修改目标。几毫秒的确认时间独立于PID周期，不需要等待凑足若干个5ms采样。

设置命令为`H,<tolerance_mdeg>,<hold_ms>`，例如`H,500,20`。它只配置到位判定、不启动控制、不解除急停。固件默认宏在main.c：`ANGLE_SETTLE_ERROR_DEG=0.5f`、`ANGLE_SETTLE_TIME_MS=20U`。

V9保留V8的100字段，追加误差范围（毫度）、稳定时间（ms）、M1/M2/M3到位状态，共105字段；状态0纠偏、1范围内计时、2稳定到位。停止时状态回到0；上位机结合mode显示“未运行”。最大文本长度仍1280。

JSON仍为version3，可选新增`position.settling: {"toleranceDeg":0.5,"holdMs":20}`，支持表单/设备导出、导入及批量应用。旧文件没有此字段时不额外发送H；新版界面加载设备设置后，可随完整表单保存。V8固件仍可使用原角度环，但配置/显示稳定到位需V9；导入含新设置的文件时会在批量发送前检查版本，避免部分下发。

## 控制计算

```text
目标角度 → 角度PID → 限幅后的目标速度 → 现有双向速度PID → 电流
总电流 = 对应输出比例 × (重力电流 + 速度PID电流 + 静摩擦起动电流)
```

外环和内环共用现有`SPEED_LOOP_PERIOD_MS`周期，默认5ms（200Hz），每次先计算角度外环，再计算速度内环。速度滤波器仍独立更新；1ms电流发送、20Hz二阶巴特沃斯和原有补偿算法保持原样。

三台电机各有上下两组角度Kp/Ki/Kd，初始全0。按`目标角度−当前角度`的正负选组：负误差为上升组，正误差为下降组，零误差沿用上一组。方向切换复位该路角度PID历史；速度PID仍按外环生成的目标速度方向选组并保留原换向复位规则。心跳和同方向目标更新不反复清除PID积分。

角度PID沿用普通位置式`Pid_update`，直接读取当前编码器输出轴角度，不额外滤波。输出为目标速度（°/s），每路最大幅值默认50°/s，可在上位机修改为0.001～180°/s；积分限幅沿用相同幅值及既有PID抗饱和。Kp单位1/s，Ki单位1/s²，Kd无量纲。

速度内环及最终电流限幅、输出比例、重力补偿按实际上升开启、静摩擦起动及净位移撤销均沿用既有实现。角度模式也可在速度调参浮窗手动恢复相应电机静摩擦补偿，仍使用设备已生效的幅值。

角度PID为0时，外环不产生角度纠偏目标速度；若用户明确启动角度模式，内环仍按零目标速度闭环，并不是断电模式。停止角度环或Q急停才请求三路零电流。

## 上位机使用

1. 先导出设备当前参数，再烧录新版固件，Ctrl+F5刷新上位机。
2. 现有速度环必须先调好；角度外环复用这些参数。
3. 打开“角度环调参”，选M1/M2/M3和上升/下降，设置角度PID及该电机速度上限，点击“应用所选方向角度PID / 速度上限”，以设备回读为准。修改当前使用组或速度上限会复位该路外环并撤回缓存外环速度/PID电流；只修改未使用组、且上限不变时不清除当前外环历史。
4. 填写三路输出轴目标角度（°），点击“启动角度环”。运行中再次点击可更新目标。修改表单、应用参数、打开图表都不会自行启动。角度环、电流测试及独立速度环互斥。
5. “角度跟踪”与速度跟踪一致：三台选择/对比、目标与实测/误差视图、3位小数、1～60秒窗口、固定纵轴、鼠标真实采样读数、峰峰/RMS/标准差、暂停回看、最大化、拖动和独立缩放。附加读数显示外环目标速度、速度PID电流和最终raw电流；仍可同时打开速度跟踪观察内环。
6. 关闭跟踪浮窗仅隐藏；关闭角度调参浮窗或点击停止发送S。Q、Esc、失焦、隐藏、关闭页面继续走既有停止路径。暂停图表不停止角度控制。

现有角度保护始终有效：任一路≤−80°，或进入负角度后回到/越过0°，在下一次1ms输出时锁定三路零电流。上电+12.77°和首次进入负角度不触发0°保护。角度目标允许±180°输入，但超出现有机械保护区间的运动会触发上述急停，不会为了跟踪目标而绕过保护。

角度目标每约50ms发送心跳；固件超过300ms未收到心跳或CAN反馈不新鲜时停止三路输出，不自动恢复重力模式。配置本次上电有效，不写Flash。未烧录、未运行真实电机；离线测试不代表实机跟踪验收。

## 协议

- 新模式`mode=6`：角度外环＋速度内环；模式0～5含义不变。
- `A,<a1_mdeg>,<a2_mdeg>,<a3_mdeg>`：目标角度×1000，范围±180000，进入/刷新角度模式。值0是目标0°，不是停止指令。
- `J,<motor>,<direction>,<kp_milli>,<ki_milli>,<kd_milli>,<max_speed_milli>`：配置指定电机、指定方向的角度PID；direction为−1/+1。增益×1000，非负；速度上限单位°/s×1000，每电机双向共用，范围1～180000。此命令不启动控制，不解除急停。
- `U`仍设置速度环/滤波周期，同时同步角度PID的dt并复位历史。
- `S/G/K/T/B/P/R/V/D/F`原有格式和含义不变。A与现有运动指令一样受串口急停队列作废机制约束。

V8共100字段（包含首字段V8）：前76字段与V7相同；后24字段依次为三路目标角度（毫度）、M1上升/下降与M2上升/下降与M3上升/下降的18个角度PID增益（×1000）、三路速度上限（°/s×1000）。原来的`speedTarget`在角度模式下就是外环实际生成的目标速度，`pidOutput`仍为内环电流输出，不重复发送额外外环输出字段。

上位机仍可读取V2～V7，角度功能必须有V8字段才可启动。最大遥测文本长度现为1280字符，流式拆包及整数单位转换保留。
