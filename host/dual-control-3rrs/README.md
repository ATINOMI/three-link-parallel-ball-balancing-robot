# DualSense → 3-RRS

本次轴向设置仅更新网页。已运行 input_version=2 服务时，刷新页面即可，无需重启服务或烧录固件；最早版旧服务需先使用当前启动脚本更新。

双击 `start_control.bat`，浏览器打开 **http://127.0.0.1:8877/**。使用 Chrome / Edge 的 Web Serial 连接平台 USB。先关闭旧调参页面对串口的占用。手柄通过 USB 接入，静止约 2 秒校准；点击「开始控制」才开始跟随。

- 手柄 Roll / Pitch 相对开始时姿态控制平台，手柄 yaw 不参与。**默认 Pitch 转轴对齐圆盘中心指向 M3 的径向线**（模型方位角240°），Roll 轴与其垂直；通过有限旋转变换映射，不用小角度近似。平台自身的从属 yaw、XY 平移仍按给定模型求解。屏幕 X/Y 读数仍是模型轴，不是手柄轴。
- **方向键 ↑ 抬升、↓ 下降，每次等效电机角变化 5°**，按住不重复；左摇杆不再调节高度。以当前高度对应的水平平台共同关节角作为等效角，上键减5°、下键加5°，由原闭环换算新Z。在有倾斜时只改变Z、保留手柄姿态目标，因此三路实际角度不一定都恰好改变5°。
- **O / ○** 回到三路 **12.77°**。正在跟随时，复位完成后把当时手柄姿态重新作为水平参考并继续跟随；未开始时按 O 只复位并保持，不自动开始姿态跟随。
- 超出严格逆解可达范围：保持上一有效目标，手柄**红灯 + 持续震动**。请求回到可达范围后恢复跟随、**蓝灯**。无效高度请求不累计；下一次按键基于最后有效高度重新计算，反向键可退出边界。
- **Q / 界面急停**：三路电流清零。页面隐藏、串口/手柄失联或遥测超时也停止，重新操作开始按钮才恢复。

## 姿态灵敏度

控制栏的「姿态灵敏度 / 倍」同时缩放手柄Pitch与Roll相对开始参考的角度变化。默认1倍，支持0～10倍；0.5倍表示手柄倾斜10°时按5°姿态输入计算，2倍表示按20°计算。0倍保持开始时平台倾斜姿态；方向键Z高度步进仍正常。

灵敏度同轴向设置一起在本机保存。沿用原localStorage键，旧配置只补默认灵敏度1，现有对齐角、交换状态与两轴正负号原样保留；修改灵敏度也不重置轴向。「恢复Pitch对齐M3」仅恢复轴向，不重置灵敏度。停止后才能调节倍率，设置本身不发送运动指令。

## 页面轴向设置

在姿态图右上角展开「轴向对齐」。可选择平台 X/Y 或 M1/M2/M3 对齐预设，输入坐标旋转角，交换手柄 Pitch/Roll，并分别选择正向或反向。也可以直接拖动图中彩色 Pitch+ / Roll+ 箭头；两轴始终垂直。小屏幕时设置位于姿态图下方。

0° 基准表示手柄 Roll 对齐平台 X、Pitch 对齐平台 Y；默认150°基准使 Pitch 对齐中心到 M3 的240°径向。交换只互换手柄两路输入，各轴正负号属于对应手柄输入。图下方给出最终两路正向轴的实际方位，平台 X/Y/Z 仍是原模型坐标。

设置自动保存在本机当前浏览器，刷新后恢复；「恢复 Pitch 对齐 M3」恢复默认。设置变化不发送任何电机指令。控制、复位或保持时编辑和拖动均锁定，先按 Q 停止再改，重新开始时以当前手柄和平台姿态建立参考。

## 固件

同时支持V11固件（108字段，追加角度环最小速度）；V10仍可运行。本次兼容更新只需刷新网页，已保存的轴向与灵敏度保持原样。

**必须先烧录本次 V10 固件**：`E:\HAL32\F4\three_motor\build\Debug\three_motor.elf`。

按照最新要求，已取消原来的 **−80° / 负角度回到 0°** 固定角度锁定。保留原最终参数、角度外环/速度内环、电流限幅、S 急停、100 ms 电机反馈和 300 ms A 指令超时。V10 与 V9 都是 105 字段，用版本号区分此控制策略。旧 V9 只显示数据，本界面禁止启动控制。

新工程不写 PID 或其他参数，只发目标 `A,<mdeg>,<mdeg>,<mdeg>` 与停止 `S`。上电仍在既定手动初始位置建立 12.77° 标定。O 键发送角度目标，不重置编码器累计值。

原调参台已补充 V10 回读兼容，并显示「固定角度保护已取消」。该调参台直接测试电机时没有本工程的姿态逆解检查。手柄控制范围由本工程逆解判定；模型没有给出碰撞、机械干涉或球铰摆角限制，这些不在数学可达性检查覆盖范围内。

## 模型与显示

原文完整保存在 `docs/`，实现于 `web/kinematics.js`。参数与固件一致：r0=126、rp=137、L1=60、L2=102 mm。采用原文 Rx·Ry·Rz、从属 yaw、**Yp=−rp·r21**，检查切向闭合、实根、初始装配分支、三维闭环残差和步进路径；接近支链奇异位置拒绝控制。协议仍有 ±180° 编码范围，并非恢复 0°/−80° 保护。

由 12.77° 与原闭环关系得到水平初始高度约 **76.994 mm**。屏幕实线和数字为编码器经固件正解估计的姿态；虚线为最后有效控制目标。未连接时明确显示「初始姿态示意」。
