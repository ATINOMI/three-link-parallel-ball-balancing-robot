# 手柄平台控制约定

- 模型源为 `docs/3RRS_inverse_kinematics_strict_3D_obsidian.md`，不得用二维投影替代严格三维闭环，保留 Yp 负号、从属 yaw、初始装配分支与全三维残差检查。
- 手柄只控制 Roll/Pitch，不使用手柄 yaw。模型计算的从属 yaw 必须保留。默认Pitch轴指向中心—M3径向线（模型240°），Roll轴与之正交；用户已授权在图中配置整体对齐旋转、Pitch/Roll互换与各自正负号，均只作用于手柄输入，不改模型轴或电机编号；使用有限旋转变换映射到模型psi_x/psi_y，不改变原几何模型。
- 升降改用方向键上/下的按下沿，每次水平平台等效共同关节角减/加5°并换算Z；按住不重复，左摇杆不调高度。倾斜时维持姿态，仅改变Z。越界步进不累计，下一按键从最后有效高度计算。手柄服务输入协议input_version=2，不得静默使用旧服务。
- 负电机角度方向为平台上升；初始标定均为 12.77°。O 是物理角度目标复位，不是修改编码器零点。
- 当前用户明确取消 0° / −80° 固定保护，范围由严格逆解判定。保留 S/Q 急停、电流限幅、反馈与心跳超时。
- 必须先 V10 固件。V10 字段与 V9 一致，但表示固定角度保护已取消。禁止兼容旧固件后静默开放本项目运动控制。
- 不可达时继续发送最后有效目标，不裁剪请求、不发送部分支链目标；红灯与震动持续到恢复可达。正常蓝灯。
- 新页面或重连不得自动启动运动；需用户点击开始或按 O。失联、数据过期、页面隐藏时急停，禁止自动恢复运动。
- 保留既有固件最终 PID / 重力 / 滤波参数；新工程只发送 A/S，不在连接时覆盖用户调参。
- C++17；设备调用只在 SDL 主线程；HTTP 线程只通过原子状态交换。用户负责实机验收，不自动发送实机运动用于测试。

- 轴向设置保存于浏览器localStorage（3rrs-axis-mapping-v1），默认rotationDeg=150、swap=false、两轴sign=+1。控制/复位/保持期间锁定编辑；图中箭头代表各手柄输入的正向旋转轴，平台X/Y标记保留。设置、加载或拖动不得发送运动指令，重新开始时采集当前参考。

- 灵敏度sensitivity默认1，范围0～10，同时乘在手柄两路相对角度上，再做正负号/互换/有限旋转。0仅暂停姿态跟随，Z步进保留。沿用3rrs-axis-mapping-v1存储键，旧配置缺少sensitivity仅补1，必须保留用户当前rotationDeg/swap/rollSign/pitchSign，不能因升级重置轴向；调倍率与恢复轴向互不覆盖。控制期间锁定倍率编辑。

- 兼容V11固件（108字段，追加三路角度环minSpeed），V10继续支持；用户轴向和灵敏度存储键、配置保留。
